The workload scheduled approximately eight API operations per second; scheduling paused during the sequential reconnect, so the 120.605-second window contains approximately 110 seconds of active scheduling. This is not an uninterrupted 120-second eight-RPS test. Fixture setup took 282.454 seconds; socket ramp took 31.941 seconds. No limits, billing, IP-forwarding headers, or email settings changed.

All test data belonged to freshly created admin-confirmed `example.invalid` users. Cleanup revoked sessions and deleted owned rooms, accounts and Auth users, then checked account/room absence. The capacity report records 101 exact private fixture throttle topics for root's separate guarded SQL cleanup. The successful smoke records four more. This is a short, single-generator, single-private-room capacity sample. It does not prove email onboarding, browser rendering, geographically distributed performance, long-duration stability, or 1,000-user capacity. Broader production readiness needs separate evidence.
