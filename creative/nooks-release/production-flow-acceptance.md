## Native launch diagnosis

The reviewed Worker registers and returns `ui://notable/workspace-v2.html` with `text/html;profile=mcp-app`, tool `_meta.ui.resourceUri`, compatible outputTemplate and resource fullscreen metadata. These match the [official UI reference](https://developers.openai.com/plugins/reference). The [official UI guide](https://developers.openai.com/plugins/build/chatgpt-ui) separates resource delivery from iframe initialization over postMessage; a successful data/render tool reply cannot prove the widget mounted.

The actual route reads `/widget.html` through `env.ASSETS` and emits an error if unavailable. A local in-memory invocation of that route, using the built file and no network, returned exact HTML and no external script source. File SHA-256 was `56693af875ca0c63292a9485806a6191e7eb2732711b5dad2340c79dab622f1a`: HTML **2,059,848 bytes**, serialized legacy resource response **2,105,954 bytes**. The envelope exceeds 2 MiB by 8,802 bytes. No authoritative host response-size ceiling was found, so this is a transport-size hypothesis to compare against actual delivery/error telemetry, not an asserted cause.

Separately, `bridge.ts` gives ui/initialize four seconds, silently catches failure and removes the pending request; a later valid reply is ignored. The frontend agent supplied a temporary harness executing the actual bridge in a VM with a fake parent. I inspected and independently ran it: after firing the initialization timeout and supplying a valid late acknowledgment, there was one initialization request, zero initialized notifications, zero tool calls, and the next workspace call failed with the connection error. This confirms a local late-handshake dead end, not the screenshot's cause. Root owns Site/resource delivery diagnostics; frontend owns its scoped startup correction. Distinguish no resource request, transport/resource rejection, script execution failure, and absent/late bridge acknowledgment before changing metadata, authentication or source broadly. Retry only after a concrete candidate or diagnostic decision; do not repeatedly create widget instances.
